# 🛠️ Web de Fontanería y Calefacción - Fernando García Sánchez

Sitio web *responsive* y moderno diseñado para ofrecer servicios profesionales de fontanería, calefacción y reparaciones de urgencia en Zaragoza. La página está optimizada para la conversión de clientes a través de llamadas directas y contacto por WhatsApp.

🚀 **Ver proyecto en línea:** [https://1968l.github.io/mi-gestor-avisos/](https://1968l.github.io/mi-gestor-avisos/)

---

## 📱 Características Principales

* **Diseño Responsive Adaptativo:** Interfaz completamente adaptada a dispositivos móviles, tablets y ordenadores mediante `@media queries`.
* **Menú Hamburguesa Móvil:** Menú desplegable en columna optimizado para pantallas pequeñas.
* **Llamada a la Acción Directa:** Botones flotantes e integrados de *Llamar Directo* y *WhatsApp Directo* para urgencias.
* **Secciones Informativas:**
  * Inicio / Hero con propuesta de valor.
  * Catálogo de servicios profesionales.
  * Razones para elegirnos (experiencia, rapidez y garantía).
  * Formulario / Sección de contacto.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5:** Estructura semántica y accesible.
* **CSS3:** Maquetación con Flexbox, CSS Grid y diseño fluido.
* **Git & GitHub:** Control de versiones e integración continua.
* **GitHub Pages:** Despliegue y alojamiento en la nube.
